## 착수 순서

T1·T2·T4는 서로 의존하지 않으므로 아무 순서로나 가능하다.

1. ~~**T3**~~ — 완료. 코어 변경은 `WorldBuilder.Build`의 `IStepLogic` 주입 인자 하나뿐이고, 가짜 폭탄은 테스트 픽스처에 있다. 계약은 건드리지 않았다. 이 결정이 A-1 매트릭스를 5케이스로 확정했다
2. **T1** — 코어에 남은 유일한 미실행 경로(`CreatePivot`). 동결 대상에 실행된 적 없는 분기가 있는 것이 지금 가장 나쁜 상태다
3. **T2 · T4** — 서로 독립. 분량이 작다
4. **T5** — 마지막. 앞의 결과를 근거로 싣는다
